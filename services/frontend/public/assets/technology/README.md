# Technology logos

Downloaded SVG assets; no runtime requests to third-party icon services. Exact source URLs are recorded in `sources.json`.

Sources and licensing:
- Devicon: https://github.com/devicons/devicon (MIT; individual logos remain trademarks of their owners).
- Simple Icons: https://github.com/simple-icons/simple-icons (CC0).
- VSCode Icons: https://github.com/vscode-icons/vscode-icons (MIT).
- Material Icon Theme: https://github.com/PKief/vscode-material-icon-theme (MIT).
- SVG Logos: https://github.com/gilbarbara/logos (CC0 collection; logo trademarks remain with their owners).
- Dashboard Icons: https://github.com/homarr-labs/dashboard-icons (see upstream licensing).
- Zipkin symbol: https://github.com/openzipkin/openzipkin.github.io/tree/master/public/img/logo_svg (OpenZipkin project artwork).

Java and C++ use SVG rather than the previous Figma bitmap exports. All images preserve their intrinsic aspect ratio inside a square container. Dark monochrome marks receive a light CSS filter in the dark UI.
